# PokerIQ
Real-time Texas Hold'em equity calculator built with Python and Streamlit.

Uses Monte Carlo simulation to calculate win probability given hole cards, 
number of players, and community cards.

## Features
- Dropdown card selection for all inputs
- Variable simulation count (10k–100k)
- Error handling for invalid inputs
- Dark poker aesthetic UI
